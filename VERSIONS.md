# Version history

Each reviewable edition has a separate version branch. The main branch is not changed by these preview releases. Only a verified remote branch URL establishes that an edition has been uploaded; local preparation is not publication.

## v0.3 — Online learning preview

Branch: `versions/v0.3-online-foundations`

- New learning-led homepage and navigation.
- Autonomy Foundations: six connected lessons, Explorer/Standard/Deeper explanations, purposeful interactive models, original explanations, source links, and formative feedback.
- Server-graded, versioned attempts and account-linked progress; guest exploration.
- Instructor-owned cohorts, learner join codes, progress and concept-check review, submitted reflections, and administrator-managed instructor access.
- Dronability practice clearly separated from formal aptitude claims; duplicate-click and timer lifecycle fixes.
- Embedded analytics removed. Google sign-in requires explicit frontend configuration.
- About this edition explains learning results and preview data limitations.

This is a testable introductory course and cohort workflow. It is not a validated assessment instrument, complete professional curriculum, managed child-account service, certified offline lab, or production public launch. No cloud host has been provisioned by this change.

## v0.2 — Visual refresh and safety fixes

Branch: `versions/v0.2-visual-refresh`
